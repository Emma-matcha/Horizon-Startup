# 普通话命令双通道验收方案

## 结论边界

任何离线引擎、浏览器在线识别或通用语音模型给出的指标，都不等于本项目在两米距离、实际 Windows/macOS 演示机麦克风和普通话青少年用户中已经达到 99%。Vosk 与 Web Speech 必须分别记录、分别计算；不同操作系统和麦克风也必须分开统计。

## 主验收集

- 文件：`mandarin-command-test-cases.csv`
- 正样本：1000 条，10 名说话者 × 4 个方向 × 25 次；至少 6 名青少年。
- 负样本：200 条，检查非方向口令不会在测试页面误判成方向。
- 距离：屏幕/内置麦克风至说话者 2.00 m。
- 设备：实际演示用 Windows 或 macOS PC，Chrome，浏览器缩放 100%；记录操作系统、机型和麦克风。
- 条件：安静、轻声、较快、日常室内噪声、键盘/风扇噪声；每条保持测试表规定条件。
- 断网：模型首次加载完成后关闭网络，再跑一次至少 100 条抽样，确认推理仍可用。
- 在线备用：保持联网，单独重跑同一数据集，记录 Chrome 版本、网络类型与引擎 `web-speech`；不得与 Vosk 结果混合计算。

## 记录字段

在 CSV 末尾补充：`engine`、`actual`、`accepted`、`latency_ms`、`network`、`browser_version`、`notes`。识别结果必须由程序自动写入或由一名观察员记录，不能由说话者自行判定。

## 通过条件

- 正样本命令准确率 `correct / 1000 ≥ 99%`，即最多 10 条错误。
- 每个单独方向准确率均 `≥98%`，避免平均分掩盖某一方向偏差。
- 负样本方向误接受率 `false_direction / 200 ≤1%`。
- P95 端到端延迟 `≤800 ms`；拒识不计作答错，而是提示重说。
- 任意一个条件不满足：不得宣传 99%，现场演示默认键盘输入或明确标注实验状态。

## 失败分析

按说话者、方向、噪声、音量和速度分别汇总混淆矩阵。若“上/下”或“左/右”集中混淆，先调整受限词表、endpoint、关键词 boosting score 或触发阈值，再完整重跑；不得只删除失败样本。

## 隐私

默认不保存原始音频。使用 Web Speech 前必须告知测试者：语音可能被发送给浏览器的识别服务。若团队为了定位失败临时录音，必须单独征得测试者同意、使用匿名编号，并在调试完成后删除；正式网站仍只保存标准化命令与结果。
