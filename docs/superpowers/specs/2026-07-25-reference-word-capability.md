# 测试参考词与主页设置能力契约

## CAPABILITY

- 视力参考测试用户可在每个 E 字视标正下方看到一个生活场景参考词，以同一 CSS 像素尺寸直观对比真实阅读感受；用户可从主页齿轮设置中关闭或重新开启参考词，选择保存在当前浏览器。

## CONSTRAINTS

- E 字视标仍是唯一正式测试目标；参考词不参与方向答案、对错判定、等级推进、分数或趋势分析。
- 参考词默认开启，每个新视标更换一次，并且不得与上一个参考词相同。
- 参考词与当前视标必须使用同一个已校准 CSS 像素数：视标的宽高等于该数值，参考词的 `font-size` 等于该数值。
- 词库使用简短、常见、无医疗含义的双字中文生活词；字体使用系统无衬线/圆体回退栈，不加载网络字体。
- 齿轮设置入口只显示在主页，不复制到教学、测试、报告或历史页。
- 设置偏好仅保存在当前浏览器，不进入筛查报告，也不跨设备同步。
- 教学页必须单独说明参考词的用途、尺寸关系、可关闭方式及“不参与评分”边界。
- 关闭参考词后，测试页不得保留空白占位，不得改变视标的物理尺寸或位置判定。

## IMPLEMENTATION CONTRACT

- Actors：进行左右眼测试的用户。
- Surfaces：主页齿轮按钮、设置弹窗、环境教学页参考词说明、正式测试页参考词。
- States：`referenceWordsEnabled=true | false`，默认 `true`。
- Transitions：主页打开设置；切换开关后立即写入本地偏好；后续测试按最新设置显示或隐藏。
- Data：独立使用 `red-house-vision:preferences:v1`，避免修改既有筛查档案版本与历史数据结构。
- Word selection：纯函数接收历史词和随机源；优先从本轮尚未展示的词中选择，词库用完后仍排除紧邻重复，并对异常随机值安全归一化。
- Rendering：参考词和视标共享同一次校准尺寸计算；视标切换时二者随同一舞台重新挂载并执行协调动效。
- Accessibility：齿轮按钮有“打开设置”名称；开关使用 `role="switch"` 和明确的开/关状态；参考词不暴露为答题提示。
- Failure recovery：偏好数据缺失、损坏或版本不兼容时恢复“默认开启”，不得阻断测试。

## NON-GOALS

- 不新增用户自定义词库、字体、颜色或词语难度选择。
- 不记录用户是否看清参考词，也不把参考词识别加入语音命令。
- 不以参考词结果作医学结论、阅读能力判断或处方建议。

## OPEN QUESTIONS

- 无阻塞问题。后续版本可评估英文词库、自定义词库和不同文字长度的视觉等效校准；本次 MVE 固定双字中文词。

## HANDOFF

- 已具备直接实现条件。进入 `tdd-workflow`：先覆盖词语选择、本地偏好、主页设置、教学说明与测试页显隐，再执行单文件重新构建及两套 E2E 回归。
