# EdgeOne Pages 直接部署设计

## 目标

将当前本地工作区的最新版红房子视力筛查网站部署到 EdgeOne Pages，先发布预览环境并验证，再发布生产环境。此次部署不依赖 Git 提交，也不整理或覆盖工作区中已有的未提交修改。

## 约束

- 网站是 Vite + React 静态应用，生产产物目录为 `dist`。
- 离线 Vosk 中文语音模型约 42 MB，超过 EdgeOne Pages 免费版 25 MB 的单文件限制。
- 离线语音依赖同源模型加载、HTTPS，以及 `Cross-Origin-Opener-Policy` 和 `Cross-Origin-Embedder-Policy` 响应头。
- 发布需要通过用户现有的 EdgeOne 账户完成交互式登录；不得保存、输出或提交账户令牌。
- 当前工作区包含用户的其他未提交修改，部署工作只增加与 EdgeOne 上线直接相关的文件。

## 方案

采用本地构建和 EdgeOne CLI 直接上传：

1. 构建阶段把 42 MB 模型稳定拆分为两个小于 25 MB 的分片。
2. 浏览器加载离线语音时并发获取全部分片，按固定顺序合并为 `Blob`，创建临时 object URL 后交给现有 Vosk 加载器。
3. 普通页面访问不预加载模型；只有启用离线语音时才下载分片。
4. 用 `edgeone.json` 为所有静态响应设置跨源隔离、安全和麦克风权限响应头，并为带内容哈希的资源和模型分片设置缓存规则。
5. 本地执行生产构建与自动化验证后，用 EdgeOne CLI 将 `dist` 发布到预览环境。
6. 验证预览地址后，将相同产物发布到生产环境。

不采用 EdgeOne Blob 或 Pages Functions，因为测试版不需要运行时后端；也不移除离线模型，因为这会降低已经实现的语音能力。

## 组件与数据流

### 模型分片构建

新增一个独立脚本，从 `public/models/vosk-model-small-cn-0.22.tar` 读取模型，按确定的大小生成两个分片和一个清单文件。清单至少包含版本、完整文件大小、分片顺序、每片大小和完整模型 SHA-256。

脚本必须拒绝以下情况：源模型缺失、分片大于平台限制、生成后总字节数不一致，或计算出的 SHA-256 与项目保存的校验值不一致。Vite 构建前执行该脚本，原始 42 MB 文件不得进入 `dist`。

### 浏览器模型加载

新增模型分片解析器：读取清单、下载分片、检查每片长度和总长度，然后合并为 `application/x-tar` Blob。生成的 object URL 沿用现有页面生命周期回收逻辑。

任一清单或分片请求失败、长度不符或组装超时，都进入项目现有的键盘备用路径，不阻塞完整视力测试。

### EdgeOne 配置

`edgeone.json` 随构建产物发布，配置：

- `Cross-Origin-Opener-Policy: same-origin`
- `Cross-Origin-Embedder-Policy: require-corp`
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: no-referrer`
- `Permissions-Policy: camera=(), geolocation=(), microphone=(self)`
- 单页应用回退到 `/index.html`
- 模型分片和指纹静态资源的长期缓存；HTML 和模型清单使用可重新验证缓存

## 测试与验收

自动化验证覆盖：

- 构建脚本生成的每个文件均小于 25 MB。
- 分片按清单顺序重组后与原模型字节完全一致，SHA-256 一致。
- 分片缺失、网络失败、长度不符和超时时触发备用输入。
- `dist` 中不存在超过 25 MB 的文件，也不存在未分片的模型 tar。
- `edgeone.json` 包含所需响应头和 SPA 回退规则。
- 现有单元测试、类型检查和生产构建通过。

预览环境人工验收：

- 首页及完整双眼测试流程可用。
- 浏览器成功请求麦克风权限。
- 模型两个分片均返回 200，并完成一次方向语音识别。
- 刷新后静态资源可命中缓存。
- 页面响应包含 COOP、COEP、Permissions-Policy 等目标响应头。
- 键盘和屏幕按钮备用路径仍可完成测试。

只有预览环境全部通过后才发布相同构建产物到生产环境。

## 发布与回退

创建“直接上传”类型的 EdgeOne 项目，使后续可以继续用 CLI 发布本地产物。首次发布目标为 `preview`，生产发布使用同一项目。若生产版本异常，优先在 EdgeOne 控制台恢复上一个成功部署；若问题仅影响语音，现有备用输入保证核心测试流程仍可运行。

## 非目标

- 本轮不连接 Git 自动部署。
- 不绑定自定义域名或办理 ICP 备案。
- 不增加数据库、用户系统、服务端 API 或患者数据上传。
- 不重构与部署无关的界面和业务逻辑。
