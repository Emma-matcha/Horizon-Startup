# 红房子首页高保真候选视觉稿设计规格

日期：2026-07-25  
状态：方向已确认，待出图  
交付物：3 张 16:10 桌面端高保真首页视觉稿

## 1. 目标

基于经典自动验光设备中“远处红顶城堡／房屋与绿色原野”的视觉记忆，为“红房子”家庭视力筛查网站探索三套差异明确的首页方向。三稿必须让用户在首屏快速理解产品用途、2 米使用距离和主要行动，同时保持安静、可信、非诊断性的产品气质。

## 2. 固定内容与品牌边界

三稿均包含：

- 左上角“红房子”Logo，使用红色线性房屋符号和黑色中文名称。
- 右上角“登录”入口。
- 主标题“向清晰，再近一点”。
- 辅助说明“两米距离，一次安静专注的视力筛查”。
- 唯一主行动“开始检查”。
- 可读但不抢占主层级的提示：“仅用于家庭视力筛查，不替代专业验光或医疗诊断。”

三稿共同遵守：

- 暖白、炭黑与朱红为品牌主色；天空使用通透但不过饱和的自然蓝，草地使用有层次的春季嫩绿。
- 核心场景为写实白墙红顶城堡或小教堂、绿色原野和具有真实景深的植被。
- 只借鉴参考图的视觉母题，不复制原图构图。
- 不使用眼球图标、镜筒、圆形视窗、瞄准线、隧道框景或霓虹医疗蓝。
- 不把家庭筛查包装成医疗诊断，不展示“准确诊断”“近视度数”等承诺。
- 保证主要正文和按钮达到 WCAG AA 对比度；交互目标在实现稿中不小于 44×44 px。

## 3. 候选 A：远野定焦

### 视觉定位

电影感、夸张极简、安静可信。它最接近品牌现有方向，但使用全新的非对称构图。

### 构图

- 16:10 桌面画布，通透蓝天与少量自然白云占画面约 55%。
- 城堡位于右下三分之一处，距离感明确；左侧留出大面积干净天空承载文案。
- 前景只在画面下沿和右侧出现少量清晰草叶，形成“从近到远”的自然深度，不使用左右对称树框。
- 标题左对齐，字号约 72–88 px；CTA 位于标题下方，朱红实心圆角矩形。
- 页面底部以一行细小信息展示“2 米 · 约 5 分钟 · 本地保存”。

### 质感与光线

- 晴朗春日的柔和上午光，嫩绿草地保持自然明暗层次，红顶保持高识别度但不发光。
- 摄影编辑感，不出现塑料、黏土、低多边形或微缩模型效果。

### 适用判断

品牌感最强、理解成本最低，适合作为主推荐方向。

## 4. 候选 B：清晰分界

### 视觉定位

瑞士现代主义、编辑网格、理性精确。通过同一景观的清晰度差异表达筛查主题。

### 构图

- 页面使用 12 栏网格，左侧约 5 栏为暖白信息区，右侧约 7 栏为纵向景观区。
- 景观从左缘轻微失焦，向右逐渐清晰；城堡完整落在清晰区域内。
- 分界是一条柔和的垂直明暗与景深过渡，不使用滑块、镜片或可拖动控件的外观。
- 主标题拆成两行并使用大号黑体；“清晰”二字以朱红强调。
- CTA 为窄而明确的朱红按钮，下面附“开始前将先确认屏幕与 2 米距离”。
- 右下角放置极简编号“01 / 环境确认 → 02 / 分眼测试 → 03 / 趋势记录”，作为可信流程说明。

### 质感与光线

- 高级杂志版式，边界清楚、留白充分、文字严格对齐。
- 不使用蓝绿色医疗配色；技术感来自网格和排版，而不是仪器图形。

### 适用判断

产品表达最直接、设计辨识度最高，适合偏科技与竞赛展示的路线。

## 5. 候选 C：回到红房子

### 视觉定位

温暖、亲切、略带触感的家庭健康产品；避免幼稚化和卡通化。

### 构图

- 暖白纸张感背景，顶部导航简洁；主体采用偏右的大型城堡与近景草坡。
- 城堡比其他两稿更近，窗户与墙面材质可辨，让“红房子”成为情感记忆点。
- 左侧文案区域像一张轻微悬浮的无边框说明卡，但不使用厚重玻璃拟态。
- CTA 为朱红胶囊按钮；旁边以细线图标和短句说明“无需上传音频”“记录仅存本机”。
- 三个可信信息点像草地路标一样沿画面底部错落排列，但保持平面 UI 的清晰度。

### 质感与光线

- 晴朗午后柔光、轻微暖色温、蓝天白云和自然风吹草叶；阴影柔和，不使用硬描边和夸张贴纸风。
- 中文排版采用圆润但克制的黑体，避免儿童产品式大圆体。

### 适用判断

亲和力最高，适合面向青少年与家长的家庭场景，但专业感略弱于 A、B。

## 6. 生成与合成方法

- 使用用户参考图作为建筑、红顶、草地与远眺记忆的视觉参考。
- 每个方向先生成无文字的写实场景底图，再以精确排版叠加 Logo、中文文案、按钮与提示，避免生成式模型造成乱码。
- 最终输出 PNG，目标尺寸 1586×992；每稿包含完整首屏，不额外生成移动端稿。
- 文件命名：
  - `docs/design/homepage-candidates/01-quiet-horizon.png`
  - `docs/design/homepage-candidates/02-focus-boundary.png`
  - `docs/design/homepage-candidates/03-return-home.png`

## 7. 验收标准

- 三稿第一眼即可区分，不能只是同构图换色。
- 城堡、草地、天空具有一致的真实摄影质感，红顶是唯一强场景强调色。
- 中文文案完整、无错字、无生成式乱码；Logo 与按钮清晰可辨。
- 首屏只出现一个强主按钮，信息层级在 3 秒内可理解。
- 非医疗提示可读但不喧宾夺主。
- 画面不出现禁用的光学仪器隐喻。
- 在 1586×992 画布上检查安全边距、对齐、文字对比度与视觉重心。
